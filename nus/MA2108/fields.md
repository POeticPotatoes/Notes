Axioms for Addition
* Closed under addition
* Commutative (interchangeable)
* Associative (brackets)
* Zero Element $(\exist 0_F\in F)(\forall x\in F)(0_F + x = x)$
* F has additive inverses $(\exist x\in F)(\exist y \in F)(x+y=0_F)$

Multiplication:
* Closed
* Commutative
* **Associative**
* $(\exist 1_F\in F)(\forall x\in F)(x \times 1_F =x)$
* Multiplicative inverses (equals to $1_F$, excluding 0)

Distributive law: x(y+z) = xy + xz

Total Order is a relation \<x s.t. 
* exactly one of x\<y, y\>x, x=y is true (trichotomy).
* transitivity (x\<y, y\<z, x\<z), meaning no cycles

Ordered fields are ordered set with ordering \< s.t. for all x,y,z in F:
1. If y\<z, then x+y\<x+z
2. If x\>0, and y\>0 then xy\>0

## Additional Notes
* for fractions, make sure denominator is natural, not integer (cos of 0)
