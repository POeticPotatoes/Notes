## Software Development Life Cycle (SDLC)
Using sequential waterfall design:
1. Specify Requirements -> Requirements
2. Design Product -> design
3. Implement -> code
4. Test -> bug fixes
5. Deploy -> product

Good for **well-understood, fixed, effort predictable** requirements

> Higher risk of overrunning deadlines (non-delivery)

Iterative design:
* Every iteration produces feedback
* Build new iteration
* Breadth first: Trying different usable versions of product
* Depth first: Expanding on product until usable

Good for **fuzzy and evolving** requirements

> Higher wastage

### Development Characteristics
* Greenfield (start from scratch)
* Brownfield (build on existing), harder
* Breadth-first is harder than Depth-first

> To enable iterative development, course will cover some of each topic per week
